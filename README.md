# FlightInfo ✈️

FlightInfo is a simple Android application that displays flight information using Skyscanner's Backpack Android UI components.

## Features

- Displays flight information
- Shows flight number
- Shows departure airport code and time
- Shows arrival airport code and time
- Uses Skyscanner Backpack `BpkCardView` and `BpkText`
- Simple and clean Android UI

## Technologies Used

- Kotlin
- Android Studio
- XML Layouts
- ConstraintLayout
- Skyscanner Backpack Android
- Android SDK API 33+
